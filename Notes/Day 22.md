## 📖 Theory

### What are embeddings?

An **embedding** is a numeric representation of text — a list of numbers (a vector) that captures the *meaning* of a word, sentence, or document, rather than just its literal characters. A model trained to produce embeddings maps similar meanings to similar vectors, even when the actual words used are completely different.

### Text → vector

Turning text into an embedding means passing it through an embedding model, which outputs a fixed-length list of numbers (e.g., 384 or 1536 numbers, depending on the model). This vector isn't human-readable on its own — its usefulness comes from how it relates to *other* vectors.

```python
text = "How do I reset my password?"
vector = embedding_model.encode(text)
# vector -> [0.021, -0.183, 0.077, ..., 0.412]  (hundreds of numbers)
```

### What is a vector?

A vector is simply an ordered list of numbers, which can be thought of as coordinates in a (very high-dimensional) space. Two vectors that are "close together" in that space represent text with similar meaning; vectors that are "far apart" represent unrelated meaning.

### Semantic similarity

Semantic similarity is how close two pieces of text are in *meaning*, regardless of exact wording. Embeddings make semantic similarity something that can actually be measured mathematically — by comparing how close two vectors are to each other.

### Keyword search vs semantic search

- **Keyword search** (used in Week 3) — matches based on shared words. If the question and the document don't use the same words, the match fails, even if they mean the same thing.
- **Semantic search** — matches based on shared *meaning*, using embeddings. Different wording that expresses the same idea will still be found.

### Similar meaning ≠ same words

This is the core insight of the week. Consider:

> "How do I reset my password?"
> "I forgot my login credentials."

These two sentences share almost no words in common, yet they're clearly about the same underlying problem. A keyword search would likely miss the connection. A well-trained embedding model places both sentences close together in vector space, because it has learned that they express related meaning.

## 🐞 Common Errors

| Error | Likely Cause | Fix |
|---|---|---|
| Wrong embedding model | Using a model not suited for the task (e.g., an image embedding model for text) | Confirm the model is specifically a text embedding model |
| API key issue | Missing or invalid key for the embedding provider | Double-check `.env` has the correct key for whichever service generates embeddings |
| Vector dimensions mismatch | Comparing embeddings generated by two different models | Always use the same embedding model for everything being compared |
| Empty text | Passing an empty string to the embedding model | Validate text isn't empty before generating its embedding |
